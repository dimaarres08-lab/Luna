# Luna Messenger — Android MVP

Откройте папку проекта в Android Studio. Android Studio предложит синхронизировать Gradle.
После синхронизации: Build → Build APK(s).

Минимальная версия Android: 8.0 (API 26).
Пока это UI-прототип: сообщения хранятся только в памяти приложения. Сервер, регистрация, база данных, push и реальные звонки будут подключаться следующим этапом.
